# I-m-never-die
It's a Trojan, but not just any

💀 Description
I'm Never Die is an experimental Windows Batch script designed to demonstrate malware-like behaviors through Windows command-line operations.

The project explores persistence mechanisms, file attributes, startup execution and automated file generation.

⚙️ Features

Startup persistence: Attempts to place a Batch file in the Windows Startup directory.
Hidden files: Uses Windows file attributes to conceal generated files.
Visual interface: Displays a custom terminal screen.
File generation: Demonstrates automated creation of multiple .bat files.
Directory manipulation: Uses Windows CMD commands to interact with user directories.

🧬 Technical details

Property	Description
Language	Batch (.bat)
Platform	Windows
Execution environment	CMD
Persistence technique	Startup folder
File attributes	System / Hidden / Read-only
File generation	Automated
